# 33 — новые встроенные функции (built-ins)

Встроенные функции не требуют импорта — они часть языка, как `len`, `cap` или
`append`. В **Go 1.21 (2023)** к ним добавились три: `min`, `max` и `clear`.

## Содержание

| Пример | Тема | Версия Go |
|---|---|---|
| [01_min-max](01_min-max/) | `min` / `max` — любой набор аргументов, любой упорядочиваемый тип | 1.21 |
| [02_clear](02_clear/) | `clear` — очистка map и срезов | 1.21 |

## Запуск

Раздел — один модуль (`go.mod`, `go 1.21`). Каждый пример — пакет `main`:

```sh
cd 33_builtins
go run ./01_min-max
go run ./02_clear
```

## Шпаргалка

### min / max
```go
min(3, 7)              // 3   — два аргумента
max(5, 2, 8, 1)        // 8   — сколько угодно аргументов
min("apple", "pear")  // apple — работают и со строками
max(lo, min(x, hi))   // clamp: ограничить x диапазоном [lo, hi]
```
- Тип результата = тип аргументов.
- Не путать со `slices.Min`/`slices.Max` (раздел 32): те берут ОДИН срез,
  встроенные — отдельные аргументы.

### clear
| Аргумент | Что делает | Меняет длину? |
|---|---|---|
| `map` | удаляет все пары (`len == 0`) | да (→ 0) |
| срез | обнуляет все элементы (0/""/nil) | **нет** |

```go
clear(m)       // map: становится пустым
clear(s)       // срез: [1 2 3] → [0 0 0], len прежний
s = s[:0]      // а так срез «опустошают» по-настоящему
```
- Для срезов `clear` полезен, чтобы убрать ссылки на старые объекты (помощь GC)
  при переиспользовании буфера.
- `clear` убирает из map даже ключи `NaN`, которые нельзя удалить через `delete`.
