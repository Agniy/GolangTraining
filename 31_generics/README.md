# 31 — дженерики (generics)

**Дженерики** (параметрический полиморфизм) — крупнейшее дополнение языка со
времён его выхода: Go 1.18 (2022). Позволяют писать функции и типы, работающие
с разными типами данных, **сохраняя проверку типов на этапе компиляции**.

## Шпаргалка

### Синтаксис
```go
func Name[T any](arg T) T { ... }          // параметр типа у функции
type Stack[T any] struct { items []T }     // параметр типа у структуры
func (s *Stack[T]) Push(v T) { ... }       // методы повторяют [T]
type Set[T comparable] = map[T]bool        // обобщённый алиас (Go 1.24)
```

### Три вида ограничений
| Ограничение | Что разрешает |
|---|---|
| `any` | любой тип (псевдоним `interface{}`) |
| `comparable` | типы с `==`/`!=` (например, ключи map) |
| свой интерфейс `~int \| ~float64 \| ...` | перечисленные типы; `~` — «и типы с таким базовым» |

`cmp.Ordered` (Go 1.21) — готовое ограничение для `<`, `>` (числа и строки).

### Правила
1. Тип обычно **выводится** из аргументов — `[T]` писать не нужно.
   Явно указывайте, только когда вывести не из чего (нет аргументов типа T).
2. У **методов** нельзя вводить собственные новые параметры типа — только
   параметры типа-получателя.
3. Выбор: **дженерики** — одна логика для многих типов с типобезопасностью;
   **`any`** — когда тип действительно произвольный и неважен.
