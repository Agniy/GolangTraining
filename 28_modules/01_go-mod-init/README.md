# 01 — go mod init

**Go Modules** (Go 1.11, 2018) — официальная система управления зависимостями
и версиями. Заменяет старый подход с `$GOPATH/src`.

## Что такое модуль

Модуль — это набор пакетов, версионируемых вместе. Корень модуля помечается
файлом `go.mod`, в котором указаны:

- **module path** — путь импорта модуля (например `example.com/hello`);
- **версия Go** — минимальная версия для сборки;
- список зависимостей (`require`) — появится, когда импортируете чужой код.

## Как создать модуль

```sh
mkdir hello && cd hello
go mod init example.com/hello   # создаёт go.mod
```

## Запуск этого примера

```sh
cd 28_modules/01_go-mod-init
go run .
```

Ожидаемый вывод:

```
Hello from a Go module!
```

## Полезные команды

| Команда | Что делает |
|---|---|
| `go mod init <path>` | создать новый модуль |
| `go build` / `go run .` | собрать/запустить (зависимости подтянутся автоматически) |
| `go mod tidy` | привести `go.mod`/`go.sum` в порядок |
| `go list -m all` | показать все модули в сборке |

## Важно про этот репозиторий

Остальной курс (папки 01–27) написан в стиле GOPATH (без `go.mod`). Каждый
пример в разделе `28_modules/` — **отдельный самостоятельный модуль** со своим
`go.mod`, чтобы продемонстрировать модульную систему, не ломая старую структуру.
