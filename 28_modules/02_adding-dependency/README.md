# 02 — добавление зависимости

Показывает, как модуль использует **внешний пакет** и как Go фиксирует версии.

## Шаги

1. Импортируем пакет в коде:

   ```go
   import "rsc.io/quote"
   ```

2. Подтягиваем зависимость:

   ```sh
   go mod tidy            # рекомендуемый способ: добавит нужное, уберёт лишнее
   # или явно конкретную версию:
   go get rsc.io/quote@v1.5.2
   ```

3. Запускаем:

   ```sh
   go run .
   ```

   Вывод:

   ```
   Hello, world.
   Don't communicate by sharing memory, share memory by communicating.
   ```

## go.mod и go.sum

- **`go.mod`** — список прямых и косвенных (`// indirect`) зависимостей с
  версиями. `rsc.io/quote` тянет за собой `rsc.io/sampler` и
  `golang.org/x/text` — поэтому они появились как `indirect`.
- **`go.sum`** — криптографические хеши *каждой* зависимости. Гарантирует
  воспроизводимость и защищает от подмены кода. Этот файл **коммитят** в git.

## Версионирование (semver)

Go использует семантическое версионирование: `vMAJOR.MINOR.PATCH`.

- `go get rsc.io/quote` — последняя совместимая версия;
- `go get rsc.io/quote@v1.5.2` — точная версия;
- `go get rsc.io/quote@latest` — самая свежая;
- major-версии ≥ 2 включают суффикс в путь импорта: `rsc.io/quote/v3`.

## Полезные команды

| Команда | Что делает |
|---|---|
| `go mod tidy` | синхронизировать go.mod/go.sum с реальными импортами |
| `go list -m all` | дерево всех модулей сборки |
| `go mod why rsc.io/sampler` | объяснить, зачем нужна зависимость |
| `go mod graph` | граф зависимостей |
